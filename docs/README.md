# Midway

Midway is a protocol for acquiring NFTs on behalf of an application through a
shared, on-chain buying process. An application registers, defines what it
wants to acquire, and Midway handles quoting, acquisition, and settlement
against the underlying market.

This documentation covers how to integrate with Midway, the concepts behind
requests and settlement, and the full contract reference. Start with the
[Quickstart](quickstart/README.md) to register an application and make your
first request, or jump straight to the [Reference](reference/README.md) for
deployment addresses and contract details.
